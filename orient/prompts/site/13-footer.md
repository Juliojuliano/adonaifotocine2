# Seção 12 — Footer

## Estrutura visual

- **Tema:** Dark (preto puro #000)
- **Layout:** Uma linha centralizada minimalista
- **Função:** Fechar a página sem chamar atenção

## Copy

```
© Orient — Made in Japan since 1950
```

## Notas de execução

- Padding vertical: 40px 24px
- Texto centralizado, `font-size: 12px`
- `letter-spacing: 0.12em`, `text-transform: uppercase`
- Cor: `rgba(255, 255, 255, 0.6)` (branco 60%)
- `border-top: 1px solid rgba(255, 255, 255, 0.08)` pra separar da seção anterior

## Filosofia do footer

O footer aqui é **deliberadamente minimalista** — só copyright + credencial do país. Sem links, sem colunas, sem newsletter, sem redes sociais.

Motivo: a landing termina com CTA final forte. Adicionar footer complexo criaria escape routes competindo com a conversão. Landing de produto único não é site institucional.

Se precisar adicionar (LGPD, política de privacidade, etc), coloca como link único ao lado do copyright, no mesmo tamanho, sem destaque.

## Sem mídia gerada

100% tipografia mínima.
