# Pasta de recebimento (staging)

Solte aqui os arquivos brutos gerados nas ferramentas de IA (Nano Banana 2 /
Veo 3.1), com **qualquer nome**, antes de serem processados e movidos para
`assets/img/` ou `assets/video/`.

Esta pasta não é publicada no site — é só um ponto de entrega temporário.
Os arquivos aqui dentro (exceto este README e o `.gitkeep`) ficam fora do
git (ver `.gitignore` nesta pasta) porque são grandes e o produto final já
fica versionado nos destinos corretos.

Veja `orient/prompts/ASSETS-CHECKLIST.md` para a lista exata de arquivos
esperados e `orient/scripts/reencode-video.sh` para o passo de re-encode
dos vídeos.
