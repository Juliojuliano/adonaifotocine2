Falta configurar o Cloudinary em assets/js/main.js (chave CLOUDINARY_CLOUD_NAME). Veja o passo a passo no README.md do projeto, seção "Painel de upload".

Acesso ao painel

Digite a senha combinada com a Adonai FotoCine para postar as fotos de um evento.

Este painel não usa login de verdade — é só uma senha combinada, suficiente para uso interno. Não poste dados sensíveis de clientes aqui.
